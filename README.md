# Bengali Poetry Reel Maker

Android version of the original Tkinter Bengali Poetry Reel Maker, rebuilt with Kivy.

## Features
- Paste Bengali poems and split stanzas using blank lines
- Calm, Dark, Romantic, and Rain moods
- Adjustable typewriter speed and stanza hold duration
- Play / Stop animated poem preview
- Export each stanza as a PNG image to the app's private storage

## Build APK
1. Open the **Actions** tab in this repository.
2. Select **Build Android APK**.
3. Press **Run workflow** (or wait for a build after a push).
4. Open the completed run and download the **Poetry-ReelMaker-APK** artifact.

The APK is built by GitHub Actions using Buildozer and Kivy.
